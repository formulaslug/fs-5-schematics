# Harness Research
All the things I want to investivate/test:

## Wire
Investigate cost of:
- PTFE insulated wire
- Tefzel
- Any other higher performance wire types
- Pre-twisted CAN wire (potentially in smaller gauges) (potentially shielded with braid or foil)

Source and attempt crimping smaller (lighter and more flexible) wire in ATS connectors (22, 24, 26, 28 AWG)

## Smaller inline connector
We currently use ATS/ATM connectors for inline connections to things like outboard sensors. Choose a smaller and lighter connector that comes in 2,3,4 pin variants which is confidence inspiring, easy to crimp, and ideally fairly cheap.

## Fully sealed harness
- How much weight does this add?
- How hard is it to do?

## Conecntric twisted harness
- Try it with two different wire guages
- What kind of setup does it take to do quickly?
- Any additional cost/materials?

## Whole-harness shielding
- Can we purchase expandable braid or another shield type which could allow for this?
- Research if shielding the entire bundle is actually beneficial for noise-isolation 

## Sheathing
Different types I know of:
- Heat shrink
- PET "finger trap"
    - Comes in cool colors
- Tape wrap
- Cloth split
- Cloth stretchy

Pick a few to try based on research for ease of use, cost, protection and find vendors.

## Mechanical/Strain Relief
- Design a strain relief boot for the ATS connectors
- Try making maintanence loops
- Source better harness tape which is non-stretchy, sticks well, and does not leave residue after thermal cycles
